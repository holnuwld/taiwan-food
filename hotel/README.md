# 🏨 대만 타이베이 에미레이트 리워드 추천 호텔 상위 50선 심층 비교 대시보드

> **에미레이트 스카이워즈(Emirates Skywards) 마일리지 vs 외부 3개 사이트 최저가 실시간 비교 분석 및 구글 실데이터 리뷰 정합성 검증 대시보드**

## 📌 프로젝트 개요

* **대상 지역**: 대만 타이베이 주요 9개 구 (시먼딩, 타이베이 메인역, 중산구, 다안구, 신이구, 송산구, 반차오구, 스린구, 베이터우구)
* **일정 기준**: 2026년 11월 11일(수) ~ 11월 14일(토) · 3박 4일
* **투숙 기준**: 성인 2명 · 객실 1실
* **분석 대상**: 에미레이트 스카이워즈 호텔 검색 결과 상위 50개 호텔 전수

## 🎯 핵심 기능 및 분석 기준

### 1. 1마일당 원화 가치(KRW/mile) 산출 및 색상 표기 규칙
* **마일당 가치 계산식**: 
  $$\text{마일당 가치 (원/마일)} = \frac{\text{외부 3개 사이트 3박 최저 현금가 (KRW)}}{\text{1박 마일리지} \times 3}$$
* **색상 규칙**:
  * **파란색 (`상위 20%`, 10개 호텔)**: 마일당 가치 **6.87원 이상**으로 마일리지 사용 효율이 극상인 호텔.
  * **빨간색 (`하위 20%`, 10개 호텔)**: 마일당 가치 **4.68원 이하**로 마일리지 소진이 비효율적인 호텔.
  * **일반색 (`중간 60%`, 30개 호텔)**: 보통 수준의 마일리지 효율.

### 2. 크리티컬 부정 리뷰 주의 표기
* 담배 냄새, 층간/벽간 소음, 하수구 악취, 곰팡이/무창 등 치명적 불만이 보고된 호텔 7선은 **[▲ 리뷰 8선 보기] 버튼을 눈에 띄는 빨간색**으로 강조 표기하여 예약 위험을 사전에 방지합니다.

### 3. #너의 추천 챕터 (AI 맞춤 엄선 호텔 5선)
사용자 제시 3대 엄격 기준 충족:
1. **마일 가성비 상위 40% 이상 (5.80 ~ 9.57원/마일)**
2. **담배 냄새 & 층간/벽간 소음 불만 ZERO (일본 직영 이중 차음재 / 5성급 방음)**
3. **위생 및 치명적 리스크 ZERO**

### 4. 고화질 ArcGIS World Street Map 통합 위치 지도
* Esri ArcGIS 고화질 타일 탑재로 워터마크 및 깨짐 현상 없이 선명한 지도 제공
* 50개 호텔 및 주요 MRT 역 환승 핀 클릭 시 실시간 가격, 마일리지, 인접 출구 팝업 연동

### 5. 구글 지도·트래블 실데이터 리뷰 8선 및 정합성 검증
* 각 호텔당 **긍정 5개 / 부정 3개 실리뷰 8선 (총 400개 리뷰)** 수집
* 실제 작성자 계정, 별점, 작성 시기, 원문 텍스트 및 Google Travel 원문 링크 1:1 매칭
* 검증자 실데이터 캡처본 탑재 (`evidence_gmaps_*.png`)

## 🛠 실행 방법

1. 브라우저에서 원하는 대시보드를 직접 열람합니다:
   ```bash
   start index.html              # v1: 럭셔리/프리미엄 50선 대시보드
   start taiwan-hotel_v2.html    # v2: 10,000~15,000 마일 가성비 50선 대시보드
   ```
2. v2 데이터 재빌드 및 정합성 검증 테스트:
   ```bash
   node generate_taiwan_hotel_v2.mjs
   node verify_v2_dashboard.mjs
   ```
